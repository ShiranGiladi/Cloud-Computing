# Cloud Computing - Trivia Game

The purpose of the system is to teach the user about cloud computing, which includes topics such as types of clouds, service models, cloud infrastructure architecture, etc. 
The system will teach the user about cloud computing through a trivia game.

Welcome screen:
- Press on Log In button to move to Log In page.
- Press on Sign Up button to move to Sign Up page.
![image](https://github.com/user-attachments/assets/e5c7a279-1cb9-4e88-8fdb-f364c5652582)


Log In screen:
- Enter username and password.
- Click on Connect to log in to the game.
- Click on Sign Up button if you don't have an account.
- Click on Back button to go back to Welcome screen.
- Note: by not entering all the fields or entering wrong username/password and click on Connect, the user gets an error message.

Sign Up screen:
